# Control de Gastos App

## Descripción

Aplicación móvil desarrollada en Android Studio utilizando Kotlin y Jetpack Compose, que permite registrar y visualizar gastos personales.

---

## Sprint 1

### Funcionalidades

* Registro de gastos en memoria
* Cálculo del total
* Validación de datos

### Pruebas realizadas

* Inserción de datos correcta
* Validación de valores negativos
* Cálculo del total acumulado

---

## Sprint 2

### Funcionalidades

* Interfaz gráfica con Jetpack Compose
* Registro dinámico de gastos
* Visualización del total en tiempo real
* Lista de gastos en pantalla

### Pruebas realizadas

* Registro desde interfaz
* Validación de datos inválidos
* Actualización automática del total
* Visualización correcta de los gastos

---

## Tecnologías usadas

* Kotlin
* Android Studio
* Jetpack Compose

---

## Uso de la aplicación

1. Ingresar nombre del gasto
2. Ingresar valor
3. Ingresar categoría
4. Presionar "Agregar gasto"
5. Visualizar total y lista de gastos
